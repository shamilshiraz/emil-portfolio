- [ ] Decide whether the contact form should use a hosted endpoint; set `endpoint` if so.
- [ ] Run `npm install`, `npm run dev`, and test the full scroll/overlay flow.
- [ ] Test both themes on desktop and mobile.
- [ ] Review the project drawer and project detail transitions with the final project content.
- [ ] Confirm final copy, SEO metadata, analytics, and hosting setup.
